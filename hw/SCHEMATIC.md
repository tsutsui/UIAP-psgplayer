# UIAPduino YM2149F PSG Player 回路図 補足

- YM2149F⇔UIAPduino 間の接続は [README.md](../README.md) の接続表のほうが
  わかりやすいと思います

- C1 の 5V平滑の 47uF は気休めですが適当な容量を使ってください

- YM2149F 右の出力側は「デモで音が鳴れば何でもいい」という回路なので参考です
- RV1 の半固定抵抗は秋月電子で販売されている
  [SUNTAN TSR-3386T-EY5-503TR](https://akizukidenshi.com/catalog/g/g108013/)
  を使っていますが、
  [商品ページの画像](https://akizukidenshi.com/img/goods/2/108013.jpg)
  にある通り、通常の可変抵抗とは異なり
  「ボリュームを物理的な1番端子の方向に回すと電気的な接点は3番端子側に近づく」
  という構造なので配線時は要注意です
- U3 スピーカーアンプは [Amazon](https://www.amazon.co.jp/dp/B094D4C637) や
  [AliExpress](https://ja.aliexpress.com/item/4000396074386.html) で売られている
  HXJ8002 アンプですが、入出力端子の間隔が 2.54mmピッチでないなど使いづらいので
  [秋月電子製 PAM8012 アンプ](https://akizukidenshi.com/catalog/g/g108217/)
  のほうが作りやすいと思います
- J2 ステレオジャックは品番としては秋月電子で売っている
  [マル信無線電機製 MJ-352W-O](https://akizukidenshi.com/catalog/g/g108958/)
  ですが、接続するスピーカーに合わせて直結含め都合のいいものを使ってください
- JP1 のジャンパはステレオジャックにモノラルプラグを差す場合はオープン、
  ステレオプラグを差して左右両方から音を出したい場合はショートさせてください。
  ただし、ステレオスピーカー接続時は8Ω以上（＝並列接続で4Ω以上）のものでないと
  たいていのアンプは駆動しきれないと思います
